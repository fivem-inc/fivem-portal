# 引き継ぎ（場所予約 /rooms）

このファイルは **場所予約を担当する人の引き継ぎ**です。

- もう一方の担当（備品購入申請・残業・FAQ など）の引き継ぎ … `docs/引き継ぎ-申請系.md`
- 2人で開発するときの決まりごと・毎回の作業ルール … `CLAUDE.md`

🚨 **新しい記録は、この案内のすぐ下に足してください**（古いものは見出しを
「▶ 前セッション」に下げる）。ファイルを分けてあるので、もう一方の担当と
同じ場所を編集してぶつかることはありません。

📍 **`▶▶` はこのファイルに1つだけ**（＝いまの最新）。古くなったら必ず
`▶ 前セッション` に下げてから、新しいものを上に足すこと。

🚨 **古い記録の中に「CLAUDE.md に記録を保存」と書かれている箇所がありますが、
2026-08-31 の分割で無効になりました。** 読むのも書くのも、このファイルです。

💡 配色・UIの決まりごとなど、**2人共通のルールの一部は
`docs/引き継ぎ-申請系-アーカイブ.md` の中にあります**（新しい画面を作るときは、
そのファイルを `🎨🔒` `🏗️ 新規ページ` で grep してください。
