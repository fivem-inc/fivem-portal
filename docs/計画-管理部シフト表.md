# 計画：管理部シフト表（2026-10-14 ユーザー確定・一問一答／作るのは 10/16 以降）

## いまの状態
- 管理部には担当（クラス・役割）が無く、シフトは勤務表（weekly_shift_patterns＝いつものシフト）だけ。
- 管理部の人（メインの部門＝管理部）は 2026-10-14 時点で8人（正社員4・パート4）。うち3人は、こどもシフト表にも入っている（校の役割・レッスン・3F/5Fで動ける人）。

## 決まったこと
1. **入力しない表**：勤務表から自動で作る。勤務表を直すと、この表も変わる（二重に入力しない）。
   置き場所はシフト管理の［管理部シフト表］（こども・大人のシフト表の隣）。
2. 見せ方は2つ（モック：配布資料/管理部シフト表_モック.png）
   - **曜日で見る**（初め）：曜日を選ぶと、校ごとに「だれが何時から何時まで」を時間の帯で（横＝6時〜21時）。校ごとに色。休みの人は下に1行。
   - **人ごとに見る**：縦＝人・横＝曜日。マスに「校＋時間」。
3. **こどもシフト表に入っている分も見せる**：曜日で見るは帯の上にオレンジの点線、人ごとに見るはオレンジの小さな字（「こども：17:40〜 5F レッスン」）。
   読むのは決定済みのこどもシフト表（大人シフト表の分も同じ形で出せる）。
4. **締め作業の担当**：四条本校だけ。管理部の人の中で、その曜日に四条本校でいちばん遅く終わる人に「締め」の印（自動）。
   - 同じ時刻に終わる人が2人以上いるときは、表の上でどちらかを選ぶ。選ぶまでは「締め：未定」（ユーザー確定 A）。
     選んだ結果は保存する（新しい表：曜日・選んだ人・その時の候補）。勤務表が変わって1人に決まるようになったら、選んだ結果は使わない。
   - 2026-10-14 の勤務表では、同じ時刻になる曜日は無い（どの曜日も1人に決まる）。

5. 見られる人：今のシフト管理と同じ人（シフト管理を開ける人＝shift_patterns の権限）だけ（ユーザー確定 A）

6. 締めの「選ぶ」ができる人：マネージャー以上と管理者だけ（ユーザー確定 B）。ほかの人には「締め：未定」と見えるだけ。
   🚨 DB でも確かめる（is_manager_plus() か管理者）

7. 出す曜日は、こども・大人のシフト表と同じ月〜日（休館日・社員出勤日の「出」の日は出さない・ほかとそろえる＝ユーザー確定）

8. 印刷・Excel：ほかのシフト表と合わせて付ける（ユーザー確定 A）

## 作り（案）
- DB：締めの選び直しの表（曜日・選んだ人・その時の候補・選んだ人・日時）と、書く関数（マネージャー以上と管理者だけ・anon を外す）。
  それ以外は今ある表（weekly_shift_patterns・staff_main_work_areas・決定済みのこども／大人シフト表）を読むだけ
- 画面：ShiftManagementTab に［管理部シフト表］。勤務表の読み込み（lib/shiftRosterApi）と、人ごとの表の材料（こども・大人の表の分）を使い回す
- 締めの判定は1か所（lib に関数を1つ）。画面・印刷・Excel が同じものを呼ぶ
