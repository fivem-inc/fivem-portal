# 計画：労働契約書（労働条件通知書）をアプリで交わす（2026-10-08・調べたこと／未着手）

ユーザーの依頼（2026-10-06）：「労働契約書もアプリでできるのか。画像を見てもらって、画面で手書きサインをもらって確認する、など方法を考えて。法律的にも（あとでいい）」

🚨 法律の最終的な判断は社労士に確かめること（ここに書いたのは調べた範囲のまとめ）。

## 1. 法律の決まり（調べた範囲）

| こと | 決まり | アプリでやるときの条件 |
|---|---|---|
| 労働条件の明示（労基法15条・労基則5条） | 原則は書面で渡す | **本人が希望すれば電子でよい**（メール・SNS など）。ただし**本人が印刷して紙にできる形**（PDF など）に限る |
| パート・有期の「昇給・退職手当・賞与の有無・相談窓口」（パート・有期法6条） | 文書で渡す | 本人が希望すれば電子でよい（同じく印刷できる形） |
| 2024年4月からの明示事項 | 就業場所・業務の「変更の範囲」（全員）、有期は更新の上限・無期転換の申込みの機会と転換後の条件 | 書式（ひな形）にこの欄があること |
| 契約そのもの（労働契約法） | 口頭でも成り立つ（形式の決まりは無い） | 画面での同意・手書きサインでも契約は成り立つ。ただし「本人が同意した」と後で示せる記録が要る |
| 電子署名の効力（電子署名法3条） | 本人による一定の電子署名があれば、本人が作ったと推定される | 画面の手書きサインは**電子署名法の電子署名そのものではない**（推定の効果は弱い）。代わりに「だれが・いつ・どの版に同意したか」の記録（ログ・文書の指紋）を残して証拠にする |
| 保存（労基法109条） | 労働関係の重要な書類は5年（当面は3年の経過措置） | 電子で保存してよい（見られる・印刷できる・改ざんが分かる形で） |

## 2. アプリでのやり方（案）

1. 管理者が、その人の労働条件通知書（兼 雇用契約書）の PDF を登録する（入社・退職の手続きの［入社］の項目から）
2. 本人のホームに「労働条件通知書を確かめてください」。開くと PDF を全部見せる（最後まで見ないと次へ進めない）
3. 「電子で受け取ることを希望します」に本人がチェック（🚨 これが無いと電子交付にならない）
4. 画面に指で手書きサイン → ［同意して署名する］
5. アプリが残すもの：サインの画像・同意した日時・ログインした人・使った端末・**PDF の指紋（ハッシュ）**・どの版か。サインを重ねた PDF を作って保存
6. 本人に控え（サイン入り PDF）をメールで送る＋アプリからいつでも見られる・印刷できる
7. 会社側も同じ画面で確認者のサイン（任意）。入社の確認の「契約書：会社保管」に自動でチェック

## 3. 作るときの注意

- 🚨 個人の情報なので、**非公開の保管場所**（Supabase Storage の非公開バケット）に置き、本人と管理者だけが見られるようにする。リポジトリ（Public）には一切入れない
- 🚨 容量：無料枠は 1GB。PDF 1通 200KB ほどなら 46人×数通で足りるが、使用量の画面で見張る
- 🚨 保存は5年。消さない（掃除の cron の対象にしない）。退職後も残す
- 紙を希望する人には紙で渡す（電子は「本人の希望」が条件のため、選べるようにする）
- 改ざんが分かるよう、保存した PDF の指紋を記録しておき、見るときに照らし合わせる

## 4. 決めること（作る前にユーザーに聞く）

- 社労士に確かめるか（書式・電子交付の同意の文言）
- 対象：新しく入る人だけか、いまの全員の契約の更新でも使うか
- 会社側のサインを付けるか
- 紙との並行（希望する人は紙）でよいか
