## 決まったこと（2026-10-20 ユーザー確定・色つきモックで決定）
1. 表の上に［✏️ シフトを変更する］（青・その画面でいちばん押すボタン）
2. 押すと窓「いつから変えますか？」：［今日］［明日］［来月1日］＋日付を選ぶ／［やめる］［次へ］
3. 表の上に黄色い帯「M/D（曜）から変えます。変えたいマスを押してください。」［日付を変える］［やめる］（画面を動かしても上に残る）。押せるマスは薄い青の枠
4. マスを押すと、画面の真ん中に直す窓（今の直す欄の中身をそのまま入れる）。［やめる］＝そのマスを開く前に戻す／［このマスを直す］＝閉じる（下書きに残る・マスは黄色）
5. 続けて別のマスも直せる。最後は今までどおり下の［決定済みの表に保存（M/D から）］→ 確かめ → 保存
6. 日付を選ばずにマスを押したときも、先に 2 の窓を出す（日付を決め忘れたまま保存しない）
7. マスを押す直し方は残す（新しい期の表を一から作るときに何十か所も続けて直すため）
8. 右下の［PDF］［列の一覧］［行の種類・書き添え］［レッスンできる人］［設定］：押したら選ばれた色、開いた欄まで画面を動かす
9. こどもシフト表・大人シフト表の両方（同じ部品 KidsShiftPanel）。データベースは変えない
10. 社内FAQ 3件（docs の migration 20261020231712_faq_shift_tables.sql・未適用）は、画面ができてから文を合わせ直して入れる

## レビュー（2026-10-20・UI/UX とシニアエンジニアの2体）で決まったこと・作ったもの
- 日付は applyFrom 1つだけ。帯の［日付を変える］［やめる］は guarded（未保存があれば 保存する／捨てる／やめる）を通す
- 日付を変えた直後は、その日の表を読み終えてから窓を開く（pendingOpen・loadedFor）。押した帯は開始時刻（fromMin）で探し直す
- ［直さずに閉じる］＝窓を開いたときの下書き（この表の分を丸ごと）に戻す（共通の人は別の列も書き換えるため）／［この内容にする］＝保存済みと同じになったマスは下書きから外す（ユーザー確定 案1）
- 窓の中の「保存してある表に戻す」は「↩ M/D の表のとおりに戻す」（案は「↩ 案1の保存した内容に戻す」）
- 外側を押しても閉じない。Esc は何も変えていなければ閉じる／変えていれば「このマスの直しを取り消しますか［戻る］［取り消す］」。Ctrl+Enter＝［この内容にする］
- マスを開く入口はすべて openCell（表のマス・列の見出し・校の見出し・共通の人・曜日の書き添え・列を足す・⚠️の一覧・人ごとに見る）。同じマスを2回押しても閉じない
- こどもの表も押した時刻の帯だけ出す（大人と同じ仕組み・［この曜日のすべてを出す］）
- 保存したら「変える」状態を終える。緑の知らせに［続けて M/D から直す］。案に切り替えたら終える
- 上の日付の欄は「表を見る日」。変えている間は押せない（日付は帯から）
- 日付の窓：［今日］［明日］［来月1日］＋日付。過ぎた日は窓の中に黄色で「過ぎた日のシフトも書き換わります」
- 黄色い帯：🚨 position: sticky は効かない（管理画面の外側の箱が overflow-x: hidden・2人共通の部品なので触らない）。帯が上に隠れたら同じ帯を画面の上に固定して出す（IntersectionObserver）
- 未保存のマスは今までどおりオレンジの枠（モックの黄色は誤り＝「変わった所に印」と同じ色になる）。押せるマスは内側の薄い青の影
- 右下の［PDF］［列の一覧］［行の種類・書き添え］［レッスンできる人］［設定］：開いている間は青・aria-pressed。開いた欄の見出し「▼ 名前」［✕ 閉じる］と「ここで変えた内容はすぐ保存されます（下書きにはなりません）」（PDF は除く）。開いたらそこまで動かす。保存前の確かめ（guard）も動かす
- 部品：components/admin/ShiftCellDialog.tsx（窓の外枠 ShiftDialogFrame・直す窓）／ShiftEditDateDialog.tsx。lib/shiftRoster に mdWithWeekday
- 🚨 作っている途中で、新しい部品に既存の ShiftEditModal.tsx（勤務変更の画面）と同じ名前を付けて上書きした。型チェックで見つけて git から戻した（差0）。新しいファイルを作るときは同じ名前が無いか先に確かめる
- 試し（localhost:4173・保存は押していない）：日付の窓／来月1日→帯→マス→窓（14:10 の帯だけ）／直さずに閉じる＝元どおり／この内容にする＝未保存1／Esc（変えていない＝閉じる・変えた＝聞く→取り消す）／保存済みと同じに戻す＝未保存なし／日付を決めずにマス→先に日付の窓→読み直してから開く／帯の固定／設定のボタンの色と動き。大人の表は日付の窓→窓まで（手元の表に授業の行が無く、帯で絞るところは未確認）
