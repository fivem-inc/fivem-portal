## ✅ ユーザーの決定（2026-09-29・蒸し返さない）
- スマホは**交通費と同じ「箱」方式**（1日分を入れて［＋ 申請リストに追加］→［複製］で日付・時間を変えて追加→［申請する（◯件）］）。
  カレンダーで複数日を選ぶ案（案X・案Z）は「内容を日ごとに変えたい」ので採らない
- 残業ページに**［まとめて申請］タブ**を新しく作り、**マネージャー・社長・管理者だけ**で試す。事前申請も**事後報告も**入れられる
- **まず表入力（パソコン）で全部の種類を出せるようにする**。1行に収まらない入力は**その日の下に2行目**を開いて入れる
- 問題なく動けば、いつものフォームの「新しく出す」部分を［まとめて申請］に差し替える。
  実績報告・差し戻しの再提出・修正は「履歴」から1件を開いて直すものなので、1件分の画面として残す
- 差し替えた古い部分は、2〜4週間の猶予のあと消す（git に残る）
- **差し替えたあとのタブの名前は元の［事前申請・事後報告］に戻す**（［まとめて申請］のタブは試しのあいだだけ）。
  タブは今と同じ2つ（［事前申請・事後報告］［履歴・実績報告］）で、中身が箱の形になるだけ。パソコンの［📋 残業申請「表入力」］は今までどおり

## 2行目（表入力）の形（見本：会話で提示）
- ふだんの日は1行のまま。必要な日だけ、その日の下に2行目が開く
- 時間の欄の左に［時間｜終日｜打刻ズレ］の切り替え（打刻ズレは「過ぎた日の新しい申請」だけ）
- 勤務地の選択に「移動あり」→ 2行目に「◯:◯〜◯:◯ 校A → ◯:◯〜◯:◯ 校B」
- 終日 → 2行目に 種類［時間外調整休｜振替休日｜欠勤］、振替休日なら振替元の日・時間・校
- 打刻ズレ → 2行目に 打刻の時刻と理由、黄色の注意（「仕事をしていた時間は残業です」）
- 締め切りを過ぎた日 → 表の上の案内に［経理に許可を依頼する（◯日）］。依頼中・許可済みは行に札
