## 動き
1. ほかのページにいるとき、新しいものが来ると 🏠 に赤い数字
2. 🏠 を開いた時点で「見た」。数字は消える。新しかったものに「新着」
3. 次に開いたとき、残っているものには灰色の小さな「確認済み」
4. 答える・対応すると、その帯自体が消える

## 作りの案（エンジニアのレビュー対象）
- 帯ごとのデータの読み込みを共通の部品（lib）に出し、帯と数字で同じものを使う（数え方を2か所に書かない）
  - 管理者からのお知らせ：fetchActiveAnnouncements（既存）
  - 締め日：rpc my_payroll_close_notice（既存）
  - 安否確認：useSafetyPendingCount（既存のフック）
  - 催促：scheduled_reminder_responses（App.tsx の中に直書き）
  - 有休奨励日：paid_leave_encouragement_*（App.tsx の中に直書き）
  - 出勤のお願い：rpc shift_adjust_my_part_requests（パートだけ）
  - 残業の目安超え：rpc overtime_threshold_banner（既存）
- 「見た」の記録：端末の localStorage（見たお知らせのキーの一覧）。DB に書かない。スマホで見てもパソコンの数字は残る
- 数え直すのは、アプリを開いたとき・前面に戻ったとき・新しいベル通知が来たとき（lib/refreshBus・useRefreshOn）だけ。ページを移るたびには数えない（2026-09 に通信量が無料枠の90%に達した経緯がある）
- ナビの数字は lib/navItems の badges に home を足す。App.tsx（2人共通）を触るので場所予約の担当に事後連絡

## 2体のレビュー（2026-10-17・UI/UX デザイナーとシニアエンジニア・主な指摘）
- 分けていない人の 🏠 のボタン名は「交通費」（lib/navItems.ts）。そこに赤い数字が付くと「交通費でやり残しがある」と読まれる
- 「確認済み」は残業の受理の言葉と同じ。目安超えの帯で「上長が確認した」と読まれるおそれ → ボタンは［読みました］、畳んだ見出しだけ「確認済み」
- 「見た」の記録を端末（localStorage）に置くと、ログアウト（hooks/useAuth の handleLogout の localStorage.clear）で全部が新着に戻る・スマホとパソコンでずれる → DB に「ホームを最後に見た時刻」を持つ
- ナビはページを移るたびに付け直される（useRefreshOn は付いた時点で1回読む）。帯ごとに読むと 1回あたり5〜8本・月およそ16万本
- 残業の目安超えは閉じたものを SQL の中で除いている（overtime_threshold_banner）。残すなら本番の実定義から _v2 を作る（引数を足すと PGRST203）
- 上長の目安超えは部門ごとに1枚。消える条件を決めないと最長1か月残る
- 表に無い帯：NotificationBanner（打刻の確認・調整の提案・再提出の依頼）・パートの有休申請・退職の手続き
- 「新しいお知らせはありません」の判定（描いた文字を見ている）が畳んだ帯と合わなくなる
- 並び：答えるもの → 新着 → 受理待ちのまとめ → 確認済み（閉じた形）

## 決まったこと（2026-10-17 追加・ユーザー確定）
6. **DB の関数1本**（my_home_feed）にまとめる：画面は1回だけ聞き、DB が中で各お知らせを調べて「種類・キー・新着／確認済み」の短い一覧だけを返す（本文は返さない）。帯もナビの数字もこれを見る（判定は DB の1か所）
7. そのうえで **10分以内なら読み直さない**（ページを移っても聞かない・前面に戻ったとき・関係する通知が来たときは読み直す）
8. **残業の目安超え（上長）**：超えている時間がなくなるまで帯を出し続ける。［確認した］を押すと 🏠 の数字は消えるが、帯は大きさを変えずにそのまま出し、枠に「確認済み」を付ける。
   超えた人が新しく増えたら、もう一度数字を出す（新着に戻る）（2026-10-17 ユーザー確定）
9. **管理者からのお知らせ**：［確認した］でホームから消してよい。過去のお知らせを見られる入口（届いた日・確認した日・掲載期限）があるとよい。掲載期限が切れたら消える（ユーザー案・A／B／C を提示中）
10. **残業の目安超え（本人）**：上長と同じ。超えている間は出す・［確認した］で数字だけ消える・✕ と［後で再通知］はやめる。
    数字は自動でまた付く：①超えた時間がさらに伸びたとき ②毎月の決まった日（今も送っている日）（2026-10-17 ユーザー確定）
11. **管理者からのお知らせ**：A＝［確認した］か掲載期限でホームから消える＋ホームの下に「過去のお知らせ（N件）›」（届いた日・確認した日・掲載期限・本文）。
    並び：いちばん上に「掲載期限が切れたのにまだ確認していないもの」、その下は新しい順（掲載中で未確認には「ホームに出ています」）（2026-10-17 ユーザー確定）
12. **「見た」「確認した」の記録はアカウント（DB）**。1人×1お知らせで1行＋ホームを最後に見た時刻。掃除：掲載が終わって1年たったら消す（cron）（2026-10-17 ユーザー確定）
13. **🏠 のボタン名は今のまま**（分けていない人は「交通費」）。ホームのいちばん上に「新しいお知らせ◯件」の1行で補う（2026-10-17 ユーザー確定）
